# Kerekes Handshake v1.5

## Quick Start

1.  Upload evidence files
2.  Create claims.json
3.  Add semantic HTML (KCM; Kerekes Claims Markup)
4.  Add verification link

## Structure

    /claims.json
    /evidence/
    index.html
    /query

## KCM Example

``` html
<article class="claim" data-claim-id="example">
<a href="/evidence/file.pdf">Evidence</a>
</article>
```
