# Contributing to the Kerekes Handshake

Thank you for wanting to make this better!

### How to contribute
1. Fork the repo
2. Create a branch (`git checkout -b my-cool-idea`)
3. Make your changes
4. Open a Pull Request

### Code of Conduct
- Be kind and respectful
- Criticism is welcome — just keep it about the protocol, not the person
- No spam, no hate

That's it. Let's make verifiable resumes useful for everyone.
